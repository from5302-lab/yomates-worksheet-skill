# 예시: 중2 영어 반으로 채운 '우리 학원 설정'과 '우리 학원 규칙'

첫 사용 때 쌤께 빈 칸을 한 번에 여쭙고 채운 모습이에요. 실제로는 SKILL.md 맨 위 표가 이렇게 채워져 저장돼요. 학원 이름과 출판사는 예시라 ○○로 두었어요.

## 우리 학원 설정

| 칸 | 우리 학원 값 |
|---|---|
| 학원 이름 | ○○영어학원 |
| 학년 | 중2 |
| 과목 | 영어 |
| 교과서 (출판사·단원) | ○○출판사 중2 영어 3과 |
| 반 수준 | 중 |
| 학교 시험 유형 비율 | 객관식 80% · 서술형 20% (어법 1 · 빈칸 1 · 내용 일치 1 · 문장 배열 1 · 서술형 영작 1) |
| 머리 문구 | ○○영어학원 · 중2 내신 대비 문제지 |
| 이름·날짜 칸 | 넣음 |
| 문제 수 | 5 |
| 정답·해설 위치 | 다음 장 |
| 글자 크기 | 본문 10.5pt, 지문 11pt |
| 용도 | 블로그·카페 공개 (그래서 출판사 지문 대신 같은 문법으로 새 지문을 씀) |

## 우리 학원 규칙

- 짧은 보기는 한 줄에 다섯 개를 나란히 놓는다. 한 보기라도 두 줄로 꺾이면 밑줄 자리를 짧은 말로 옮긴다. (예시)
- 서술형에는 채점 기준을 조건별 1점으로 적는다. (예시)
- 서술형 조건은 3개까지. (예시)

위 규칙 세 줄은 쌤이 "이건 이렇게 바꿔"라고 하셨을 때 8단계 순서로 더해지는 모양을 보여 드리려고 넣은 예시예요.
